In the current age of AI agents, it's never been more important to have proper isolation between workloads in a multi-tenant environment. runc isn't secure enough since every container shares the host kernel. gVisor's runsc makes security their #1 priority, but with problematic performance overhead (mainly small-file I/O and network-heavy workloads). Enki is the container runtime that brings the worst of runc and runsc to the fingertips of the developer! Purely a learning project, might be built into something more consequential one day.
