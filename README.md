In the current age of AI agents, it's never been more important to have proper isolation between workloads in a co-tenant environment. Docker's runc isn't secure enough given it uses the host kernel directly. gVisor puts security as their #1 priority, but with problematic performance overhead (Mainly small-file I/O and large network requirements). Enki is the container runtime that brings the worst of runc and gVisor to the fingertips of the developer! Purely a learning project, might be built into something more consequential one day.
